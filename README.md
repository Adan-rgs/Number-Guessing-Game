**Number-Guessing-Game**
Solution for the [Number Guessing Game](https://roadmap.sh/projects/number-guessing-game) project from [roadmap.sh](https://roadmap.sh/)

---
**INTRODUCTION**
---
This is the Number Guessing Game!! Try your luck and try to guess a randomly generated number between 1 and 100. This is a simple command-line game made in Python

**How to Run**
---
1. Clone the repository: 
```
git clone https://github.com/Adan-rgs/Number-Guessing-Game.git
```

**How to play**
---
1. Run the game by executing the Python file
2. The program shows a welcome message and a prompt to select the difficulty level
3. Enter 1 for easy, 2 for Medium, and 3 for Hard
4. Enter a number between 1 and 100
5. If your guess is incorrect, you will receive a hint indicating whether the correct number is higher or lower than your guess
6. The game ends when you guess the number or you run out of attempts

**Difficulty levels**
---
1. Easy: 10 attempts
2. Medium: 5 attempts
3. Hard: 3 attempts

**Technical details**
---
This game is built using Python. The program uses the built-in "random" library to generate random values.
